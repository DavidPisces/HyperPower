# HyperPower — Core Topology

Selected direction: **06 / Core Topology**.

## Final construction

- Four equal outer nodes preserve the original V1 direction exactly: a balanced CPU and telemetry topology.
- Diagonal links converge around a deliberately reduced rounded center so the icon feels open rather than blocky.
- Vertical buses and split crossbars make the `H` silhouette explicit.
- The production app icon is pure black on pure white; the transparent master continues to use `currentColor`.

## Files

- `hyperpower-symbol.svg` — editable, transparent, `currentColor` master
- `hyperpower-app-icon.svg` — 108 × 108 branded launcher composition
- `png/` — transparent symbol and branded app-icon exports
- `showcase/` — four selected presentation styles
- `showcase.html` — final identity overview and downloads

## Selected showcase styles

1. **The Void** — matches a privileged system utility and emphasizes the topology.
2. **LED Matrix** — connects the mark to CPU hardware, sampling, and telemetry.
3. **Clinical Studio** — demonstrates precision, monochrome integrity, and light-mode use.
4. **UI Container** — shows the mark in its native Android app-icon context.

The previous launcher assets remain recoverable from the round-one exploration. Production Android resources use the V1 geometry with a smaller center and an adaptive-safe white/black composition.
